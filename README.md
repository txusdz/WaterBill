WaterBill Application

A C# WinForms application designed to calculate water consumption bills based on customer categories, manage invoice records, and export invoices to HTML/PDF.

Features
- Calculate Bills**: Supports Household, Administrative, Production, and Business customer types.
- Invoice Management**: Stores invoice history with date and time.
- Export Invoice**: Export billing receipts to styled HTML/PDF documents.
- Input Validation**: Prevents invalid meter index entries and empty fields.

Built With
- C# / .NET WinForms
- Visual Studio
